The outer workspace is off-black; toolbar and inspector are dark surfaces with white Manrope text. Each toolbar action uses a 24px icon button. The selected PDF geometry receives a primary blue outline and a secondary red selection marker. The inspector gives the element ID and Parquet-backed specifications in text. A tertiary green link indicator appears only after the geometry-to-record match is verified. If matching is uncertain, replace it with tertiary yellow and an explicit “Possible match” label. Below the specifications, reviewers can post comments with an authored Info, Warning, or Error tone; these comments do not alter link verification.

At narrow widths, move the inspector below the page or into a clearly labeled drawer. Keep the PDF page legible and maintain the same selection and metadata states.
